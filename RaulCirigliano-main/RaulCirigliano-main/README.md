# ArteBarro

Este repositorio contiene el sitio web personal de **Raúl Cirigliano**, un espacio dedicado a la **escultura, la cerámica artística y el proceso creativo**.

La web está pensada para acompañar la mirada del visitante desde la presentación del artista hasta la exploración de sus obras, procesos y recursos técnicos.

## 🌐 Qué encontrarás en el sitio

- **Inicio:** una presentación de la propuesta artística y la visión del trabajo.
- **Galerías:** acceso a procesos, obras terminadas y recorridos visuales relacionados con la producción.
- **Guía del Hacer:** materiales, técnicas, procesos y referencias para entender el oficio.
- **Tienda:** sección dedicada a piezas disponibles para venta.
- **Contacto:** datos de contacto, redes sociales y ubicación.

## 🎨 Propuesta del proyecto

El sitio combina una experiencia visual con contenido editorial y técnico. Además de mostrar obras, busca acercar al visitante a la forma en que el artista trabaja, observa y comparte su oficio.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS personalizado
- JavaScript
- Font Awesome para iconografía
- SEO básico con meta tags, Open Graph y sitemap

## ▶️ Cómo ver el sitio localmente

Desde la raíz del proyecto puedes ejecutar:

```bash
python -m http.server 8000
```

Luego abrir en el navegador:

```text
http://localhost:8000/public/
```

## 📦 Despliegue

El proyecto incluye configuración para despliegue estático, con soporte para servicios como Cloudflare Pages / Wrangler.
