♟️ Ajedrez Maestro: Entrenador con IA Local

Evolución de la aplicación de aperturas a un Entrenador Virtual Inteligente 100% offline, con tracking de ELO e integración LLM. Reside en ~/Escritorio/proyectos/ajedrez_entrenador-personalizado.

Arquitectura y Filosofía

Privacidad Total (Zero-Cloud)
Vanilla JS

100% Offline: No hay peticiones externas (ni OpenAI ni Firebase). No contiene carpeta .git para evitar subidas accidentales.

Almacenamiento Local: Las estadísticas, historiales y ELO se guardan persistentemente en el navegador mediante localStorage.

1. Sistema de ELO y Modo Libre

  • Dificultad IA: Niveles 1 al 5 mapeados a rangos ELO (800 a 2500).
  • Cálculo: Al dar Jaque Mate o Tablas, se ajusta el ELO del usuario matemáticamente.
  • Dashboard: Registra victorias, empates y derrotas asociadas directamente a la apertura que se jugó.
  • Entrenador IA Ajedrez

2. Coach Virtual (Ollama)

La pestaña de Perfil incluye un Coach que lee las estadísticas en formato JSON, construye un prompt y consulta a la IA local (ej: qwen2.5:7b) vía API local /api/generate para devolver sugerencias de estudio en lenguaje humano.

3. Comandos Web

Levantar el entorno web (HTML puro en Python):

bash
cd ~/Escritorio/proyectos/ajedrez_entrenador-personalizado
python3 server.py
# Abrir en: http://localhost:8000

4. Comandos Ollama (CORS)

Para que la web JS conecte con el puerto 11434, se habilitó el CORS en el Systemd. Comandos de mantenimiento:

bash
sudo systemctl start ollama
sudo systemctl stop ollama
sudo systemctl restart ollama

# Si se edita override.conf:
sudo systemctl daemon-reload
