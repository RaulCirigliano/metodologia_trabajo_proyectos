🧠 Ollama IA & Open-WebUI

Entorno de Inteligencia Artificial 100% local, privado y offline en Linux. Los scripts residen en ~/Escritorio/proyectos/ollama.

Infraestructura y Modelos

Servicio local (127.0.0.1:11434)
Local Inferencia

Modelos Descargados:

  • llava:7b (4.7GB): Visión multimodal y OCR.
  • qwen2.5-coder:7b (4.7GB): Programación avanzada y refactorización.
  • qwen2.5-coder:3b (1.9GB): Código rápido y baja latencia.
  • qwen2.5:7b (4.7GB): Razonamiento lógico en español.
  • llama3.2:3b (2.0GB): Asistente general instantáneo.
  • Entrenador IA Ajedrez

Persistencia y Almacenamiento: Todo guardado y modelo debe dirigirse a /mnt/disco_ia (externo) para proteger la partición raíz.

1. Guardado Automático (ia)

En el ~/.bashrc se configuró una función que guarda la sesión de la terminal directamente al disco externo.

bash
# Uso: ia [modelo]
ia qwen2.5-coder:7b

2. Atajos y Control en Chat

  • Ctrl + C (x1): Detiene la escritura en vivo del bot sin salir del programa.
  • /clear: Olvida el historial de la sesión (vacía el contexto temporal).
  • """ (triple comilla): Obligatorio para enviar bloques multilínea de código.
  • Entrenador IA Ajedrez

3. Gestión de Modelos e Interfaz

bash
ollama list
ollama stop <modelo>
docker start open-webui

4. Control del Servicio (Systemd)

Comandos útiles para detener o reiniciar el motor de IA si presenta problemas o si se editó la configuración (ej: CORS).

bash
# Detener el servicio
sudo systemctl stop ollama

# Recargar configuración si se modificó el archivo de servicio
sudo systemctl daemon-reload

# Reiniciar el servicio
sudo systemctl restart ollama
