🇯🇵 Tutor de Japonés con Ollama

Aplicación web interactiva servida en Flask que utiliza el contenido HTML de nihongo-app para crear un tutor de japonés por voz con IA. Los archivos residen en ~/Escritorio/proyectos/aprendiendo_japones_con-ollama.

Arquitectura del Proyecto

Flask (Web Server) + Ollama (IA) + Web Speech API
Fullstack Local

Tecnologías utilizadas:

  • Backend (Python/Flask): Sirve la interfaz y procesa el HTML de las lecciones con BeautifulSoup4 para extraer el contexto (Títulos, Gramática, Ejemplos).
  • Motor LLM (Ollama): Utiliza el modelo Llama3 o Qwen2.5 de manera local para interactuar con el alumno, inyectando el contexto de la lección seleccionada.
  • Interfaz de Voz (JS Web Speech API): Evita dependencias nativas de Python como Whisper. Usa el STT (Reconocimiento de voz) y TTS (Síntesis) directamente en el navegador.

1. Construcción y Configuración

El entorno virtual está configurado en la carpeta del proyecto.

bash
cd ~/Escritorio/proyectos/aprendiendo_japones_con-ollama
python3 -m venv venv
source venv/bin/activate
pip install Flask ollama beautifulsoup4

2. Iniciar el Tutor

Asegúrate de que el demonio de Ollama está corriendo en background.

bash
# Arrancar la aplicación Flask
cd ~/Escritorio/proyectos/aprendiendo_japones_con-ollama
source venv/bin/activate
python tutor.py

Luego abre http://127.0.0.1:5000 en el navegador.
