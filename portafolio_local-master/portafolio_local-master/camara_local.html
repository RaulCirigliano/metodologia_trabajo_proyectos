📹 Cámara Web Local (GuardianCam)

Aplicación de videovigilancia inteligente en Python puro con OpenCV y Flask. Organiza eventos por franjas horarias y soporta borrado por lotes.

Arquitectura y Motor de Detección

Despliegue activo en /proyectos/camara_seguridad
  • Ruta del Proyecto: ~/Escritorio/proyectos/camara_seguridad
  • Stack Técnico: Python 3, OpenCV (Sustractor MOG2), Flask, FFmpeg (H.264 asíncrono).
  • Estructura de Archivos: Segmentación automática por fecha y hora: grabaciones/AAAA-MM-DD/[Madrugada|Mañana|Tarde|Noche]/...mp4.
  • Acceso Seguro: Tailscale IP local y Túnel Cloudflare (HTTPS) con auth protegida.
  • Entrenador IA Ajedrez

Comandos de Inicio y Parada

Iniciar en primer plano (Terminal):

bash
cd ~/Escritorio/proyectos/camara_seguridad
./iniciar.sh

Iniciar como demonio y enlace remoto:

bash
./iniciar_segundo_plano.sh
./compartir_internet.sh

Parada total (liberar video0):

bash
./detener.sh

Lógica de Franjas Horarias

Las grabaciones (por defecto 5 min) incluyen un pre-buffer de 3 segundos en RAM y se ordenan en disco en:

  • Madrugada: 00:00 a 07:59
  • Mañana: 08:00 a 11:59
  • Tarde: 12:00 a 16:59
  • Noche: 17:00 a 23:59
  • Entrenador IA Ajedrez
💡
La interfaz web Flask permite filtrar por estas pestañas y usar batch_delete para eliminar grabaciones múltiples limpiando automáticamente las carpetas vacías.

Opciones para el Próximo Paso

Pendientes

Las mejoras futuras a definir con el usuario incluyen:

  1. Sistema de purga automática: Borrar videos de +N días o al llegar a un umbral de disco libre para no saturar el almacenamiento.
  2. Notificaciones Instantáneas: Envío de alerta con miniatura (foto) vía Telegram o Webhook directamente desde Python.
  3. Máscaras de exclusión: Ignorar ciertas zonas de la cámara (ej. ventiladores, cortinas movidas por el viento) dibujando un polígono para el filtro MOG2.
