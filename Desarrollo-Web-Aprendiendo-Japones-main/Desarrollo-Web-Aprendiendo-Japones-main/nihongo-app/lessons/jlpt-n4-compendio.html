Nivel N4

Compendio de la Preparación JLPT N4

Resumen estructurado de todas las categorías gramaticales que se estudiarán en este nivel.

1. Formas Verbales y Conjugaciones

  • Forma Volitiva (意向いこう形かたち): Invitar de manera activa o expresar la intención y voluntad propia de realizar una acción.
  • Forma Pasiva (受身うけみ形かたち): Transforma el verbo (~れる / ~られる) para señalar que el sujeto recibe la acción.
  • Forma Causativa (使役しえき形かたち): Indica dar instrucciones, permitir u obligar a alguien a hacer algo (~させる / ~させてくれる).
  • Forma Condicional (条件じょうけん形かたち): Estructuras de consulta o consejos sobre qué hacer (ej. 疑問詞ぎもんし + ~ばいいですか).
  • Construcciones con Forma Te (て形かたち):
    • ~てみます / ~てみたいです: Intentar/probar hacer algo.
    • ~てあげます/くれます/もらいます: Dar y recibir acciones o favores.
    • ~てしまう / ~てちゃう: Acción completamente terminada, a menudo con arrepentimiento.
    • ~てきます: Evolución o progreso continuo de una acción hacia el presente.

2. Intención, Decisiones y Planificación

  • ~ことにします: Expresa la decisión deliberada y voluntaria tomada por el propio hablante.
  • ~ことになります: Indica que una decisión o regla ha sido determinada por terceros o circunstancias.
  • ~つもりです / ~予定よていです: Planes e intenciones personales o eventos programados.
  • ~と思おもっています: Se está considerando o pensando llevar a cabo un plan determinado.

3. Facilidad, Exceso y Modificación

  • ~やすいです / ~にくいです: Indican que una acción es fácil o difícil de realizar.
  • ~すぎます: Sobrepasar un límite o hacer algo en exceso con resultados indeseados.
  • Adverbios (形容詞けいようしの副詞ふくし用法ようほう): Modificar verbos transformando adjetivos (い→く, な→に).
  • ~たばかり: Expresa que una acción acaba de completarse hace muy poco tiempo.

4. Obligación, Permiso y Prohibición

  • ~なくてもいいです / かまいません: No es obligatorio hacer algo (permiso para no hacerlo).
  • ~なくてはなりません / なくちゃ: Obligación imperativa de realizar una acción.
  • V[diccionario] + な: Prohibición directa e informal ("¡no lo hagas!").
  • ~が禁止きんしされています: Reglas formales o prohibiciones en un lugar determinado.

5. Causa, Concesión, Probabilidad y Finalidad

  • ~ので: Expresa causa o razón de manera más suave y formal que "から".
  • ~ても / ~でも: Concesión ("aunque" / "aun si").
  • ~かもしれません: Posibilidad o probabilidad sin afirmatividad rotunda ("tal vez").
  • ~ために / ~ように: Estructuras para señalar propósito o finalidad.
  • V[diccionario] のに...: Indica el propósito o la utilidad de un objeto o acción.

6. Percepción, Enumeración y Partículas

  • ~が見みえます / ~が聞きこえます: Percepción espontánea visual o auditiva, a diferencia de la capacidad consciente.
  • ~とか…とか: Enumerar varios ejemplos no exhaustivos.
  • Partícula + も: Énfasis o negación total en combinación con pronombres interrogativos.

7. Lenguaje Honorífico y Formal (Keigo)

  • Sonkeigo (尊敬語そんけいご): Lenguaje de respeto para elevar al interlocutor (いらっしゃる, おっしゃる, なさる).
  • Kenjougo (謙譲語けんじょうご): Lenguaje de modestia para la propia posición (お/ご...します, いたします).
  • Teineigo (丁寧語ていねいご): Expresiones corteses de uso general (です, ます, でございます).
  • お/ご...ください: Solicitar cortésmente que se realice una acción.
