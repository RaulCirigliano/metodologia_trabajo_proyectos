JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 14

Tema: ~て以来いらい / ~てからでないと (Desde que / A menos que)

📚 Gramática Principal

  • ～て以来いらい (te irai): Significa 'Desde que...'. Enfatiza que un estado ha continuado o cambiado de forma permanente desde que ocurrió ese evento. (A diferencia de ~てから, se usa para periodos más largos o cambios significativos).
  • ～てからでないと (te kara denai to): Significa 'A menos que...' o 'Hasta que no...'. Se usa para indicar que la acción B no puede suceder hasta que no se complete primero la acción A. Suele ir seguido de una negación.

上司じょうしに相談そうだんしてからでないと、この件けんは決定けっていできません。

お金きんを貯ためてからでないと、車くるまは買かえない。
