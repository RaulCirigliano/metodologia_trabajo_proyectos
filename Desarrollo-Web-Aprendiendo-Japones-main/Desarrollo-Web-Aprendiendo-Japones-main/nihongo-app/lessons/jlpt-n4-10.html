📚 Gramática Principal

  • Forma Condicional (Bakei): 'Si ocurre A, entonces B'.
  • G1: u -> e + ba (書かく -> 書かけば).
  • G2: ru -> reba (食たべる -> 食たべれば).
  • G3: する -> すれば | 来くる -> 来これば (kureba).
  • Adj-i: i -> kereba (高たかい -> 高たかければ).
  • Adj-na / Sust: -> なら (暇ひまなら).
