📚 Gramática Principal

  • Forma Plana + 場合ばあいは: En caso de que... (Para situaciones hipotéticas indeseables o instrucciones manuales). Ej. 遅おくれる場合ばあいは、連絡れんらくしてください (En caso de retrasarse, comuníquese).
  • Forma Plana + のに: A pesar de que... / Aunque... (Expresa sorpresa, queja o insatisfacción profunda). Ej. 勉強べんきょうしたのに、テストが悪わるかったです (A pesar de que estudié, me fue mal en el examen).
