📚 Gramática Principal

  • あります: 'Hay / Está'. Se usa para objetos inanimados o plantas.
  • います: 'Hay / Está'. Se usa para personas y animales (seres animados).
  • Lugar に N が あります/います: 'En (Lugar) hay (N)'. La partícula に marca el lugar de existencia, y が marca lo que existe.
  • N1(Cosa) は Lugar に あります/います: 'El (N) está en (Lugar)'. El sustantivo es el tema y ya sabemos de qué hablamos.
