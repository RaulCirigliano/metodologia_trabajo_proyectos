📚 Gramática Principal

  • これ / それ / あれ: Pronombres demostrativos. Esto (cerca mío), Eso (cerca tuyo), Aquello (lejos de ambos).
  • この / その / あの + Sustantivo: Adjetivos demostrativos. Este libro, Ese libro, Aquel libro.
  • そうです / そうじゃありません: 'Así es' / 'No es así'. Se usa para confirmar o negar preguntas de sustantivos.
  • N1 の N2: La partícula の indica posesión (Mi libro), origen/creador, o contenido (Un libro DE informática).

🌟 10 Ejemplos de Uso

A continuación, 10 ejemplos prácticos utilizando la gramática aprendida en esta lección.

これは辞書じしょです。
1. Esto es un diccionario.
それは私わたしの傘かさです。
2. Eso es mi paraguas.
あれは誰だれのかばんですか。
3. ¿De quién es aquel bolso?
この本ほんは私わたしのです。
4. Este libro es mío.
そのカメラはスミスさんのですか。
5. ¿Esa cámara es del Sr. Smith?
はい、そうです。
6. Sí, así es.
いいえ、違ちがいます。
7. No, es distinto (no es así).
これはコンピューターの本ほんです。
8. Este es un libro de computadoras (contenido).
これは何なんの雑誌ざっしですか。
9. ¿De qué es esta revista?
あれは日本にっぽんの車くるまです。
10. Aquel es un auto de Japón (origen).
