1. Propósito (~ために)

Se traduce como "Para..." o "Con el propósito de...". Se usa con verbos de voluntad y expresa un objetivo claro y absoluto. También se puede usar con sustantivos ("Por el bien de mi familia").

自分じぶんの店みせを持もつために、貯金ちょきんしています。
Ahorro dinero para (con el objetivo de) tener mi propia tienda.
家族かぞくのために、うちを建たてます。
Construiré una casa por el bien de mi familia.

2. Uso y Propósito de objetos (~のに)

Se utiliza frecuentemente con verbos como 使つかう (usar), いい (ser bueno), 役に立やくにたつ (ser útil), o かかる (tardar/costar), para indicar el propósito de una cosa o acción.

このはさみは花はなを切きるのに使つかいます。
Estas tijeras se usan para cortar flores.
