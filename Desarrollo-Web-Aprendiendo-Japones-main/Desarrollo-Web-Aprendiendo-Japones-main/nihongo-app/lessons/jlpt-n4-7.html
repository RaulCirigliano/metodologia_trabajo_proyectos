📚 Gramática Principal

  • V(ta) / V(nai) + ほうがいいです: 'Es mejor que... / Deberías...'. Se usa para dar un consejo fuerte o una advertencia médica.
  • Futsukei + でしょう: 'Seguramente...'. El hablante cree que es probable (aprox. 80%).
  • Futsukei + かもしれません: 'Tal vez... / Puede ser que...'. Probabilidad menor (aprox. 50%).
