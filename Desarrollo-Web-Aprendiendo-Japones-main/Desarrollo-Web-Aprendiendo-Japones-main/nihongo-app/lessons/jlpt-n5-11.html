📚 Gramática Principal

  • も (mo): Significa 'también'. Reemplaza a は, が y を. Ej: 私わたしは学生がくせいです。彼かれも学生がくせいです (Yo soy estudiante. Él también es estudiante).
  • 何なにも / 誰だれも / どこも: Pronombres interrogativos + も + verbo negativo = Nada / Nadie / A ningún lado.
  • Contadores: つ (Cosas), 人にん (Personas), 枚まい (Hojas/Plano), 台だい (Máquinas), 匹ひき (Animales pequeños), 冊さつ (Libros).
