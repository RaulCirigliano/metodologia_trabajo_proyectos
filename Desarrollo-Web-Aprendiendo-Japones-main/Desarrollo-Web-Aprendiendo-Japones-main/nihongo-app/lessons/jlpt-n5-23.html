📚 Gramática Principal

  • Futsukei + とき: 'Cuando...'. Verbo Diccionario (acción en futuro/progreso) o Verbo TA (acción terminada).
  • Sustantivo + の + とき: Ej: 子供こどものとき (Cuando era niño).
  • V(dic) + と: 'Si haces A, inevitablemente ocurre B'. Se usa para máquinas, direcciones y fenómenos naturales.
