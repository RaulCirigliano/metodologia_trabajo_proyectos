📚 Gramática Principal

  • Futsukei + Sustantivo: Un verbo en estilo informal puede describir a un sustantivo directamente. Ej: 読よむ本ほん (El libro que voy a leer).
  • Partícula が: En la oración que modifica, el sujeto se marca con が, no con は. Ej: 私わたしが書かいた手紙てがみ (La carta que YO escribí).
  • Tiempo / Promesa / Asunto + V(dic): 'Tiempo para...', 'Promesa de...'. Ej: 買い物かいものに行いく時間じかん (Tiempo para ir de compras).
