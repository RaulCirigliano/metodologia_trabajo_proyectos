1. Apariencia visual (~そうです)

Se usa para expresar "Parece que..." o "Tiene pinta de..." basándose en lo que se ve en ese instante.

  • Con Verbos: Raíz ます + そうです (ej. 降おります → 降おりそうです = Parece que va a llover).
  • Con Adjetivos: Eliminar い o な + そうです (ej. おいしい → おいしそうです = Tiene buena pinta/Parece rico).
今いまにも雨あめが降おりそうです。
Parece que va a llover de un momento a otro.
この料理りょうりはとてもおいしそうです。
Esta comida tiene muy buena pinta (parece deliciosa).

2. Ir a hacer algo y volver (~て来きます)

Se utiliza para indicar que se va a un lugar, se hace una acción rápida y se vuelve al lugar de partida ("Voy a... y vuelvo").

ちょっとたばこを買かって来きます。
Voy a comprar cigarrillos un momento (y vuelvo).
