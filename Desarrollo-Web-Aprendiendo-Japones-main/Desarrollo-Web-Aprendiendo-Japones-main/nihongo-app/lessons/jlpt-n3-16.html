📚 Gramática Principal

  • N + に限かぎる (Ni kagiru): 'No hay nada como...' o 'Lo mejor es...'. Expresa la opinión subjetiva del hablante de que algo es lo mejor o ideal. Ej. 夏なつはビールに限かぎる (En verano, no hay nada como la cerveza).
  • N / V(te) + ばかり (Bakari): 'Solamente / Nada más que'. Expresa que se hace algo repetidamente o solo hay una cosa, a menudo con una connotación ligeramente negativa. Ej. 肉にくばかり食たべている (No come nada más que carne).
  • N + のみ (Nomi): 'Solamente'. Equivalente formal o escrito de 'だけ'. Ej. 経験者けいけんしゃのみ募集ぼしゅう (Se busca solamente gente con experiencia).
