📚 Gramática Principal

  • N(Herramienta/Idioma) で V: La partícula で también indica con qué herramienta, medio o idioma se hace algo.
  • Sujeto は Persona に あげます: 'Dar a'. La persona que recibe el objeto se marca con に.
  • Sujeto は Persona に もらいます: 'Recibir de'. La persona de quien se recibe se marca con に (o から).
