📚 Gramática Principal

  • 1. Apariencia visual (Parece que...): V(masu sin masu) / Adj-i(sin i) / Adj-na(sin na) + そうです. Negativo: V(nasasou desu), Adj(ku nasasou desu). Ej. 降おりそうです (Parece que lloverá).
  • 2. Transmisión (Dicen que... / Escuché que...): Forma Plana + そうです. Se usa para repetir información obtenida de otra fuente (noticias, rumores). Ej. 降ふるそうです (Dicen que lloverá).
  • Clave: Fíjate bien en la conjugación antes de 'sou desu'. Si es forma Plana, es 'dicen que'. Si es raíz, es 'parece que'.

🌟 10 Ejemplos de Uso

A continuación, 10 ejemplos clave para dominar este tema en el examen N4.

空そらが暗くらいです。雨あめが降おりそうです。
1. El cielo está oscuro. Parece que va a llover (Apariencia).
天気予報てんきよほうによると、明日あしたは雨あめが降ふるそうです。
2. Según el pronóstico, dicen que mañana lloverá (Transmisión).
このケーキは美味おいしそうです。
3. Este pastel parece delicioso.
山田やまださんは来こないそうです。
4. Escuché que Yamada no vendrá (Transmisión).
この仕事しごとは難むつかしそうです。
5. Este trabajo parece difícil.
田中たなかさんはとても元気げんきそうです。
6. Tanaka parece muy enérgico (Genki es Adj-Na).
ニュースによると、事故じこがあったそうです。
7. Según las noticias, dicen que hubo un accidente.
この映画えいがはあまり面白おもしろくなさそうです。
8. Esta película no parece muy interesante.
ボタンが取とれそうです。
9. El botón parece que se va a caer (a punto de...).
彼かれは結婚けっこんするそうです。
10. Dicen que él se va a casar.
