📚 Gramática Principal

  • V(te) もいいですか: '¿Puedo hacer...?'. Se usa para pedir permiso. Para dar permiso se responde 'ええ、いいですよ' (Sí, puedes).
  • V(te) はいけません: 'No debes hacer...'. Prohibición estricta.
  • V(te) います: Además de 'estar haciendo' (progresivo), también expresa un estado permanente, resultado de una acción (Ej. Estoy casado), o una acción habitual (Trabajo en...).
  • N(Lugar/Trabajo) で 働はたらいています: 'Trabajar EN'. Se usa で. Pero N に 住すんでいます: 'Vivir EN', usa に (Punto fijo).

🌟 10 Ejemplos de Uso

A continuación, 10 ejemplos prácticos utilizando la gramática aprendida en esta lección.

写真しゃしんを撮とってもいいですか。
1. ¿Puedo tomar fotos?
ええ、いいですよ。
2. Sí, por supuesto.
ここでタバコを吸すってはいけません。
3. No debes fumar aquí (Está prohibido).
私わたしは結婚けっこんしています。
4. Yo estoy casado (Estado).
ミラーさんはIMCで働はたらいています。
5. El Sr. Miller trabaja en IMC.
私わたしは大阪おおさかに住すんでいます。
6. Yo vivo en Osaka.
カメラを持もっていますか。
7. ¿Tienes (posees) una cámara?
はい、持もっています。
8. Sí, la tengo.
IMCの電話番号でんわばんごうを知しっていますか。
9. ¿Sabes el número de teléfono de IMC?
いいえ、知しりません。
10. No, no lo sé.
