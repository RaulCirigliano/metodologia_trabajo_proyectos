📚 Gramática Principal

  • N + さえ: 'Incluso... / Hasta...'. Marca un caso extremo y obvio para sugerir que lo demás es aún más cierto. Equivalente a 'N も / N まで'. Ej. 子供こどもさえ知しっている (Incluso los niños lo saben).
  • V(て) + しょうがない / 仕方しかたがない: 'Es tan... que no se puede evitar / Inmensamente'. Igual que 'Te tamaranai'. Ej. 暇ひまでしょうがない (Estoy tan aburrido que no tiene remedio).
  • N + を問とわず (o towazu): 'Sin importar / Independientemente de...'. Se usa para indicar que una condición no importa. Ej. 年齢ねんれいを問とわず (Sin importar la edad).

6. Estoy tan preocupado por ella que no puedo evitarlo.
この仕事しごとは、年齢ねんれいや性別せいべつを問とわず、誰だれでもできます。
7. Este trabajo lo puede hacer cualquiera, sin importar la edad o el género.

水みずさえあれば、一週間いっしゅうかんは生いきられる。
10. Si al menos tengo agua, puedo sobrevivir una semana (Sae + ba).
