📚 Gramática Principal

  • V(dic) / Sustantivo + の + ために: 'Para', 'Por', 'Con el propósito de'. Indica un esfuerzo o meta clara. Ej. 家族かぞくのために働はたらきます (Trabajo por mi familia).
  • V(dic) + のに: 'Para'. Se usa seguido de verbos como 使つかう (usar), 役に立やくにたつ (ser útil), o expresiones de tiempo/dinero (かかる). Ej. これを切きるのに使つかいます (Se usa para cortar esto).
  • Diferencia: 'Tame ni' es un propósito/meta humana absoluta. 'Noni' es el uso o la función de un objeto.
