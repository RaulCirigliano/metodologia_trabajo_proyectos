JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 4

Tema: ~ところだった / ~てたまらない (Casi pasa / Sentimiento insoportable)

📚 Gramática Principal

  • ～ところだった (tokoro datta): Significa 'Estuve a punto de...' o 'Casi...'. Expresa que algo estuvo a punto de suceder pero no pasó (generalmente evadiendo un peligro o perdiendo una oportunidad).
  • ～てたまらない (te tamaranai): Significa 'No puedo soportar lo...' o 'Extremadamente...'. Expresa una emoción o sensación física tan fuerte que es imposible de reprimir.

4. Y pensar que estuve a punto de sacar 100 puntos por tan poco...

5. Si me hubiera dado cuenta tarde, casi se convierte en un incendio.

彼かれに会あいたくてたまらない。
