1. Dar consejos (~たほうがいいです)

Se utiliza para recomendar o advertir firmemente a alguien que haga algo o que no lo haga. Suena un poco autoritario, así que no se usa con superiores.

  • Para aconsejar que SÍ: Verbo (Forma た) + ほうがいいです。
  • Para aconsejar que NO: Verbo (Forma ない) + ほうがいいです。
毎日まいにち運動うんどうしたほうがいいです。
Es mejor que hagas ejercicio todos los días.
熱ねつがあるから、お風呂ふろに入いらないほうがいいです。
Como tienes fiebre, es mejor que no te bañes.

2. Predicciones (~でしょう / ~かもしれません)

~でしょう (deshou): Expresa conjetura o predicción (Aprox. 80% de probabilidad). "Probablemente..."

~かもしれません (kamoshiremasen): Expresa posibilidad (Aprox. 50% de probabilidad). "Quizás / Puede que..."

明日あしたは雨あめが降ふるでしょう。
Probablemente mañana llueva.
