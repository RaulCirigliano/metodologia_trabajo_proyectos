JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 18

Tema: ~からして (A juzgar por / Ya desde...)

📚 Gramática Principal

  • ～からして (kara shite): Significa 'A juzgar por...' o 'Ya desde...'. Se usa para señalar un detalle, generalmente algo básico o pequeño, para insinuar que todo lo demás también es de la misma manera (frecuentemente tiene una connotación negativa).
  • Nota: Es como decir 'Incluso ese pequeño detalle es así, por lo tanto, el resto seguramente también lo es'.
