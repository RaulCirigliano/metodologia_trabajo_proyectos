📚 Gramática Principal

  • N + にする: Expresa una decisión personal sobre una opción (elegir algo). Ej. コーヒーにします (Me decido por un café).
  • V(dic/nai) + ことになる: Se ha decidido que... (Decisión externa, reglas o destino). Ej. 来月らいげつ、出張しゅっちょうすることになりました (Se decidió que iré de viaje de negocios el próximo mes).
  • V(dic/nai) + ようになっている: Describe el mecanismo o la función automática de una máquina o sistema. Ej. このドアは自動じどうで閉しまるようになっている (Esta puerta está hecha para cerrarse automáticamente).
