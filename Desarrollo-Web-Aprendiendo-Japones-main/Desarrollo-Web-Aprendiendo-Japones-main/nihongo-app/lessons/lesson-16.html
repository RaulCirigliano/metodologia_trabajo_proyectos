📚 Gramática Principal

  • V(te), V(te), V: Se unen verbos en forma TE para indicar una secuencia cronológica de acciones. El tiempo verbal lo dicta el último verbo.
  • V1(te)から、V2: 'Después de V1, hago V2'. Enfatiza que V2 ocurre inmediatamente después de V1.
  • N1 は N2 が Adjetivo: Para describir una característica de algo. Ej: 'Osaka la comida es deliciosa' (大阪おおさかは食べ物たべものがおいしいです).
  • Unión de Adjetivos: Adj-i: quita い y pon くて (大おおきくて). Adj-na y Sustantivos: quita な/です y pon で (きれいで).

この部屋へやは広ひろくて、明あかるいです。

神戸こうべは静しずかで、きれいな町まちです。

7. Karina es estudiante y María es ama de casa.
お金きんを入いれてから、ボタンを押おしてください。

昨日きのう、銀座ぎんざへ行いって、友達ともだちに会あって、映画えいがを見みました。
