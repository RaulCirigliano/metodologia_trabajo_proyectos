JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 3

Tema: ~ばかりに / ~たいばかりに (Causas extremas y deseos)

📚 Gramática Principal

  • ～ばかりに (bakari ni): Significa 'solo por culpa de...' o 'solo porque...'. Expresa que una pequeña razón causó un gran resultado negativo o lamentable.
  • ～たいばかりに (tai bakari ni): Significa 'solo por el gran deseo de...'. Expresa que uno hizo un gran esfuerzo o algo irracional solo para conseguir lo que deseaba.
