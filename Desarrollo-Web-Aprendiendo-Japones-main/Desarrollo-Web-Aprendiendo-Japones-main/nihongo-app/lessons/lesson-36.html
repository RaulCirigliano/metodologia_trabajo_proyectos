1. Propósito y Objetivo (~ように)

Se utiliza para indicar que se hace una acción "con el objetivo de" lograr un estado deseado. Se suele usar con verbos potenciales o verbos sin voluntad directa.

日本語にほんごが話はなせるように、毎日まいにち練習れんしゅうします。
Practico todos los días para (lograr el objetivo de) poder hablar japonés.

2. Cambios de estado o habilidad (~ようになります / なくなります)

~ようになります: Pasar de un estado en el que no se podía hacer algo a uno en el que sí se puede. "Llegar a poder...".

~なくなります: Pasar de un estado en el que se podía hacer a uno en el que ya no. "Dejar de poder...".

日本語にほんごがわかるようになりました。
He llegado a poder entender japonés.

3. Esfuerzos continuos (~ようにしています)

Significa "hacer un esfuerzo continuo para..." o "procurar hacer...".

毎日まいにち運動うんどうするようにしています。
Hago el esfuerzo (procuro) hacer ejercicio todos los días.
