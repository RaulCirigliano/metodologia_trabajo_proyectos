📚 Gramática Principal

  • V(dic) / V(nai) + ように しています: Intentar hacer algo como hábito o hacer un esfuerzo continuo. Ej: 毎日まいにち運動うんどうするようにしています (Intento hacer ejercicio todos los días).
  • V(dic) + ようになりました: Indica un cambio de estado, pasar a poder hacer algo que antes no se podía. Ej: 日本語にほんごが話はなせるようになりました (He llegado a poder hablar japonés).
  • V(dic) / V(nai) + ように してください: Por favor, asegúrese de hacer / intente hacer (más suave que te kudasai, es para hábitos o instrucciones).

🌟 10 Ejemplos de Uso

A continuación, 10 ejemplos clave para dominar este tema en el examen N4.

毎日まいにち運動うんどうするようにしています。
1. Intento (hago el esfuerzo de) hacer ejercicio todos los días.
甘あまいものを食たべないようにしています。
2. Intento no comer cosas dulces.
日本語にほんごが話はなせるようになりました。
3. He llegado a poder (ahora puedo) hablar japonés.
泳およげるようになりました。
4. Ahora puedo nadar (antes no podía).
肉にくを食たべなくなりました。
5. He dejado de comer carne.
もっと野菜やさいを食たべるようにしてください。
6. Por favor, intente comer más verduras.
絶対ぜったいに遅おくれないようにしてください。
7. Por favor, asegúrese de no llegar tarde bajo ninguna circunstancia.
最近さいきん、よく寝ねるようになりました。
8. Últimamente, he empezado a dormir bien.
忘わすれないようにメモします。
9. Tomo notas para no olvidar.
毎日まいにちニュースを見みるようにしています。
10. Hago el esfuerzo de ver las noticias todos los días.
