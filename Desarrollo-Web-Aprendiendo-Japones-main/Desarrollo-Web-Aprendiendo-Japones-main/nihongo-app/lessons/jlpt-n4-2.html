📚 Gramática Principal

  • Forma Potencial (Kanoukei): Indica capacidad o posibilidad.
  • Grupo I: Cambia la vocal 'u' por 'e' + ru (Ej. 書かく -> 書かける).
  • Grupo II: Quita 'ru' + 'rareru' (Ej. 食たべる -> 食たべられる).
  • Grupo III: する -> できる | 来くる -> 来こられる (korareru).
  • Partícula: El objeto (を) pasa a ser (が). Ej: 日本語にほんごが話はなせる (Puedo hablar japonés).

A continuación, 10 ejemplos clave para dominar este tema en el examen N4.

私わたしは日本語にほんごが話はなせます。
1. Yo puedo hablar japonés.
漢字かんじが書かけますか。
2. ¿Puedes escribir kanjis?
刺身さしみが食たべられません。
3. No puedo comer sashimi.
明日あしたここへ来こられますか。
4. ¿Puedes venir aquí mañana?
自転車じてんしゃに乗のれます。
5. Puedo montar en bicicleta.
あそこの銀行ぎんこうでお金きんが換かえられます。
6. En aquel banco se puede cambiar dinero.
この水みずは飲のめます。
7. Esta agua se puede beber.
早はやく起おきられませんでした。
8. No pude levantarme temprano.
歌うたが歌うたえます。
9. Puedo cantar canciones.
英語えいごが読よめますか。
10. ¿Puedes leer inglés?
