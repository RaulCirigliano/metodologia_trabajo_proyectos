📚 Gramática Principal

  • Forma Volitiva (Ikoukei): Para expresar voluntad ('Vamos a...' informal). G1 (u->o+u), G2 (ru->you), G3 (suru->shiyou, kuru->koyou).
  • V(vol) + と 思おもっています: 'Tengo la intención de...'.
  • V(dic) / V(nai) + つもりです: 'Tengo el firme propósito de...' (Mayor certeza que omoimasu).
  • V(dic) / Nの + 予定よていです: 'Está programado que...' (Planes fijos o institucionales).

3. Aunque vuelva a mi país, tengo el propósito de estudiar japonés.
明日あしたは来こないつもりです。
4. Tengo la intención de no venir mañana.
７月がつの終おわりにドイツへ出張しゅっちょうする予定よていです。
5. A finales de julio está programado que haga un viaje de negocios a Alemania.
旅行りょこうは１週間しゅうかんの予定よていです。
6. El viaje está programado para una semana.
休やすもう！
7. ¡Descansemos! (Volitivo informal de 休やすむ)
将来しょうらい、自分じぶんの会社かいしゃを作つくるつもりです。
8. En el futuro, tengo el propósito de crear mi propia empresa.
車くるまを買かわないつもりです。
9. No tengo intención de comprar un auto.
飛行機ひこうきは１１時ときに着つく予定よていです。
10. Está programado que el avión llegue a las 11.
