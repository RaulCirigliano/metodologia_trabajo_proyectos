1. Verbos Intransitivos + ています

Se usa con verbos intransitivos para describir un estado continuo resultante de una acción pasada (ej. la ventana se abrió y sigue abierta).

窓まどが開ひらいています。
La ventana está abierta. (Estado)
電気でんきが消きえています。
La luz está apagada.

2. Finalización y Arrepentimiento (~てしまいました)

Indica que una acción se ha completado en su totalidad, o a menudo expresa arrepentimiento, problema o situación lamentable.

パスポートをなくしてしまいました。
Lamentablemente he perdido el pasaporte.
