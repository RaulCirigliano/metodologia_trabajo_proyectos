📚 Gramática Principal

  • V(te) もいいですか: '¿Puedo hacer...?'. Sirve para pedir permiso.
  • V(te) はいけません: 'No debes hacer...'. Prohibición estricta.
  • Diferencias de cortesía: Para dar permiso a un superior no se dice 'いいですよ' (es condescendiente), se dice 'どうぞ' (Adelante).

🎧 Escucha el diálogo (Voces IA):

Ver Transcripción y Traducción
すみません、ここで写真しゃしんを撮とってもいいですか？
Disculpe, ¿puedo tomar fotos aquí? (Permiso '~te mo ii desu ka')
いいえ、ここでは写真しゃしんを撮とってはいけません。
No, aquí no se debe tomar fotos. (Prohibición '~te wa ikemasen')
あ、そうですか。わかりました。このパンフレットをもらってもいいですか？
Ah, ya veo. Entendido. ¿Puedo llevarme este folleto? (Permiso)
はい、どうぞ。パンフレットは持もって帰かえってもいいですよ。
Sí, adelante. Puede llevarse el folleto a casa. (Concesión)
ありがとうございます。あそこに座すわってもいいですか？
Muchas gracias. ¿Puedo sentarme allí? (Permiso)
あそこはスタッフの席せきですから、座すわってはいけません。こちらの椅子いすをどうぞ。
Ese es el asiento del personal, así que no debe sentarse. Por favor use esta silla de aquí. (Prohibición)
いろいろすみません。気きをつけます。
Disculpe tantas molestias. Tendré cuidado.
