1. Causas con Forma て y で

Se puede usar la forma て (para verbos/adjetivos i) o で (para sustantivos/adjetivos na) para expresar la causa natural o incontrolable de un sentimiento o situación.

ニュースを聞きいて、びっくりしました。
Me sorprendí al escuchar (por escuchar) las noticias.
事故じこで電車でんしゃが遅おくれました。
El tren se retrasó por un accidente. (Sustantivo + で)

2. Dar razones objetivas (~ので)

Similar a ~から, pero ~ので suena más suave, objetivo y educado. Es ideal para disculparse o pedir permisos amablemente.

気分きぶんが悪わるいので、帰かえってもいいですか。
Como me siento mal, ¿podría irme a casa?
