1. Forma Pasiva Directa e Indirecta

La forma pasiva se usa cuando una persona experimenta o "sufre" la acción de otra. Se forma cambiando el verbo:

  • G1: Cambiar el sonido -i a -a + れます (ej. 書かく → 書かかれます)
  • G2: Eliminar る y añadir られます (ej. 食たべる → 食たべられます)
  • G3: する → されます / 来くる → 来こられます (こられます)
先生せんせいに褒ほめられました。
Fui elogiado por el profesor. (Pasiva directa)
犬いぬに手てを噛かまれました。
El perro me mordió la mano. (Pasiva de molestia/posesión)

2. Pasiva de Creación / Hechos

Se usa la pasiva para hablar de obras de arte, edificios o descubrimientos sin especificar quién lo hizo (o introduciéndolo con によって).

この絵えはピカソによって描えがかれました。
Este cuadro fue pintado por Picasso.
