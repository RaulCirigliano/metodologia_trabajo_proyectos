1. Hacer "tal como" (~とおりに)

Se utiliza para indicar que una acción se realiza siguiendo exactamente un modelo o instrucción previa.

  • Verbo: Forma diccionario o Forma た + とおりに
  • Sustantivo: Sustantivo + の + とおりに / Sustantivo + どおりに
私わたしがやるとおりに、やってください。
Por favor, hazlo tal y como yo lo hago.

2. "Después de" (~あとで)

Indica que una acción ocurre después de otra.

  • Verbo: Forma た + あとで
  • Sustantivo: Sustantivo + の + あとで
ご飯めしを食たべたあとで、歯はを磨みがきます。
Después de comer, me lavo los dientes.

3. Acciones complementarias (~て / ~ないで)

Se utiliza para describir el estado en el que se realiza una acción (con o sin hacer otra cosa).

砂糖さとうを入いれないで、コーヒーを飲のみます。
Bebo el café sin ponerle azúcar.
