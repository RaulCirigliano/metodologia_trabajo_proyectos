📚 Gramática Principal

  • V1(te), V2(te): Para conectar dos o más verbos en secuencia cronológica (Hago A y luego B).
  • V1(te) から: 'Después de V1...'. Indica que la segunda acción ocurre Inmediatamente o a consecuencia de la primera.
  • Adjetivos en forma TE: Para conectar oraciones descriptivas. Adj-i -> ~くて (大おおきくて). Adj-na / Sustantivos -> ~で (きれいで).
