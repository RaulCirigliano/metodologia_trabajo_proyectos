📚 Gramática Principal

  • N を V(Transitivo): La partícula を (wo) marca el objeto directo. (Ej: Comer una manzana).
  • N(Lugar) で V: La partícula で marca el lugar donde ocurre una acción. (Diferente a に que marca ubicación de existencia o destino).
  • ~ませんか: '¿Por qué no...?' Se usa para invitar a alguien a hacer algo.
  • ~ましょう: 'Hagamos...'. Forma de proponer hacer algo juntos o aceptar una invitación.
