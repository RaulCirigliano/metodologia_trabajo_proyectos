1. Preguntas incrustadas

Con palabra interrogativa (~か): Para insertar preguntas como "qué", "cuándo" o "dónde" dentro de una oración afirmativa.

Preguntas Sí/No (~かどうか): Para insertar preguntas de "si o no" ("No sé si lloverá").

会議かいぎが何時なんじに終おわるか、わかりません。
No sé a qué hora terminará la reunión.
その話はなしが本当ほんとうかどうか、調しらべてください。
Por favor, investigue si esa historia es verdad o no.

2. Probar a hacer algo (~てみます)

Significa "probar a hacer algo para ver cómo es" (ej. probarse ropa, probar comida).

この靴くつを履はいてみてもいいですか。
¿Puedo probarme (intentar usar) estos zapatos?
