📚 Gramática Principal

  • Verbos: 行いく (Ir), 来くる (Venir), 帰かえる (Volver a casa/país). Destino marcado con へ o に.
  • Forma TE: G1 (i,chi,ri->tte / mi,bi,ni->nde / ki->ite / gi->ide / shi->shite). G2 (quita masu, pon te). G3 (shite, kite).
  • V(te) います: 1) Acción en progreso (Estoy comiendo). 2) Estado resultante (Estoy casado). 3) Acción habitual (Trabajo en...).
  • V(te) ください: Petición cortés.
