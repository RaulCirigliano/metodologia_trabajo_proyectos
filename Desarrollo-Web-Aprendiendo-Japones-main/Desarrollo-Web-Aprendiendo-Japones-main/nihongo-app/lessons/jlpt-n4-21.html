📚 Gramática Principal

  • El Sonkeigo se usa para mostrar respeto a las acciones del superior (Jefe, Cliente, Profesor). ¡Nunca lo uses para tus propias acciones!
  • Verbos especiales: 行いく/来くる/いる -> いらっしゃる. 食たべる/飲のむ -> 召めし上あがる. 言いう -> おっしゃる. する -> なさる. 見みる -> ご覧らんになる. 知しっている -> ご存ぞんじです.
  • Regla general: お + V(masu sin masu) + になります. Ej. お帰かえりになります (Se va a casa).

2. El profesor lee el periódico.

3. ¿Qué va a comer/beber el jefe?
お客様きゃくさまがいらっしゃいました。
4. Ha llegado (venido) un cliente.
先生せんせいは私わたしの名前なまえをご存ぞんじですか。
5. Profesor, ¿sabe usted mi nombre?
会議かいぎの予定よていをおっしゃってください。
6. Por favor, diga el horario de la reunión.
社長しゃちょうはゴルフをなさいます。
7. El presidente juega (hace) golf.
この映画えいがをご覧らんになりましたか。
8. ¿Usted vio esta película?
どうぞ、お座すわりください。
9. Por favor, tome asiento.
先生せんせいは明日あした、学校がっこうにいらっしゃいません。
10. El profesor no vendrá (no estará) en la escuela mañana.
