JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 11

Tema: ~ざるを得えない / ~やむを得えない (No tener más remedio que)

📚 Gramática Principal

  • ～ざるを得えない (zaru o enai): Significa 'No tener más remedio que...'. Se usa cuando uno no quiere hacer algo, pero por las circunstancias es la única opción. (Se conecta a la forma Nai, quitando 'nai': 行いかない -> 行いかざるを得えない. *Excepción: する -> せざるを得えない).
  • ～やむを得えない (yamu o enai): Significa 'Inevitable' o 'Fuera de nuestro control'. Se usa como adjetivo para describir situaciones en las que no hay otra alternativa.

やむを得えない理由りゆうで、明日あしたの会議かいぎは欠席けっせきします。
6. Por motivos inevitables, me ausentaré a la reunión de mañana.
手術しゅじゅつをするのは、やむを得えない決断けつだんだった。

渋滞じゅうたいで遅刻ちこくしたのは、やむを得えない事情じじょうだ。

怪我けがが治なおらないなら、引退いんたいもやむを得えないだろう。
10. Si la lesión no se cura, el retiro también será inevitable.
