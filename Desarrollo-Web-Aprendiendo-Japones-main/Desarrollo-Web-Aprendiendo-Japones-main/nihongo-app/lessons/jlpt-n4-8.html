📚 Gramática Principal

  • Imperativo Fuerte: G1(u->e), G2(ru->ro), G3(suru->shiro, kuru->koi). Muy brusco, se usa en deportes, emergencias o de jefe a subordinado masculino.
  • Prohibición (na): V(dic) + な (na). '¡NO lo hagas!'.
  • X は Y という意味いみです: 'X significa Y'.
  • ~と 言いっていました: 'Dijo que...' (Transmitir un mensaje de un tercero a otra persona).
