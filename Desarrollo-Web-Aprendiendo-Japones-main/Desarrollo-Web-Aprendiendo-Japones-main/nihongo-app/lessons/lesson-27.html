1. Forma Potencial (可能かのう形かたち)

Uso: Expresa la capacidad de hacer algo o la posibilidad de que algo ocurra en ciertas circunstancias. La partícula を (wo) cambia frecuentemente a が (ga) cuando se usa esta forma.

  • Grupo I: Cambiar el sonido -i a -e + ます. (ej. 書かきます → 書かけます)
  • Grupo II: Eliminar ます y añadir られます. (ej. 食たべます → 食たべられます)
  • Grupo III: します → できます / 来きます → 来こられます.
日本語にほんごが少すこし話はなせます。
Puedo hablar un poco de japonés.
漢字かんじが読よめません。
No puedo leer kanjis.

2. 見みえます (miemasu) y 聞きこえます (kikoemasu)

Expresan que algo llega a nuestros sentidos de forma natural, sin intención. Es diferente de 見みられます (poder mirar intencionalmente) y 聞きけます (poder escuchar intencionalmente).

ここから富士山ふじさんが見みえます。
Desde aquí se ve el monte Fuji.
