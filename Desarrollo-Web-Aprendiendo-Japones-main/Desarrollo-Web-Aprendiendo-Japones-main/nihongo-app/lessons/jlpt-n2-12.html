JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 12

Tema: ~ことだ / ~ことか (Deberías / ¡Qué...!)

📚 Gramática Principal

  • ～ことだ (koto da): Significa 'Deberías...' o 'Lo mejor es...'. Se usa para dar un consejo fuerte o una sugerencia directa sobre lo que uno considera que es la mejor opción.
  • ～ことか (koto ka): Significa '¡Qué...!' o '¡Cuánto...!'. Se usa al final de la oración para expresar un sentimiento o emoción muy profunda (a menudo con palabras interrogativas como どんなに, どれほど, 何度なんど).
