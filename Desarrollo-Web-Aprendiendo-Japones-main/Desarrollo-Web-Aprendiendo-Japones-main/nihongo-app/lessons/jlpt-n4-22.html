📚 Gramática Principal

  • El Kenjougo rebaja las propias acciones del hablante (o de su grupo) para mostrar respeto al oyente.
  • Verbos especiales: 行いく/来くる -> 参まいる(まいる). いる -> おる. 食たべる/飲のむ/もらう -> いただく. 言いう -> 申もうす(もうす). する -> いたす. 見みる -> 拝見はいけんする(はいけんする). 知しっている -> 存ぞんじている.
  • Regla general: お + V(masu sin masu) + します/いたします. Ej. お持もちします (Se lo llevo).

2. Yo me comunicaré con el presidente.

3. Mucho gusto. Me llamo (humildemente) Tanaka.
明日あした、午後ごご３時ときに参まいります。
4. Mañana iré (humildemente) a las 3 PM.
先生せんせいのご本ほんを拝見はいけんしました。
5. He visto (humildemente) el libro del profesor.
お茶ちゃをいただきます。
6. Recibiré / Beberé el té (humildemente).
詳くわしいことは、私わたしがご説明せつめいいたします。
7. Los detalles, yo se los explicaré.
社長しゃちょうの奥様おくさまにお目めにかかりました。
8. Me encontré con la esposa del presidente (Ome ni kakaru = encontrarse).
その件けんは存ぞんじております。
9. Ese asunto, lo sé (humildemente).
アメリカから参まいりました。
10. He venido de Estados Unidos (Humilde).
