📚 Gramática Principal

  • Forma Diccionario: La forma base del verbo. G1: El sonido 'i' cambia a 'u' (Kakimasu -> Kaku). G2: quita masu y pon ru (Tabemasu -> Taberu). G3: Suru, Kuru.
  • N / V(dic)こと ができます: 'Poder / Ser capaz de'. Expresa habilidad o posibilidad.
  • 趣味しゅみは N / V(dic)こと です: 'Mi pasatiempo es...'.
  • V(dic) / Nの / Cantidad + 前まえに (Mae ni): 'Antes de...'.

🌟 10 Ejemplos de Uso

A continuación, 10 ejemplos prácticos utilizando la gramática aprendida en esta lección.

私わたしは日本語にほんごができます。
1. Yo puedo (hablar/entender) japonés.
私わたしは漢字かんじを読よむことができます。
2. Yo puedo (soy capaz de) leer kanjis.
ここで切符きっぷを買かうことができます。
3. Aquí se pueden comprar los boletos (Posibilidad).
私わたしの趣味しゅみは映画えいがです。
4. Mi pasatiempo es el cine.
私わたしの趣味しゅみは映画えいがを見みることです。
5. Mi pasatiempo es ver películas.
寝ねる前まえに、本ほんを読よみます。
6. Antes de dormir, leo un libro.
食事しょくじの前まえに、手てを洗あらいます。
7. Antes de la comida, me lavo las manos.
５年前ねんまえに日本にっぽんへ来きました。
8. Vine a Japón hace 5 años (Antes de 5 años).
ピアノを弾ひくことができますか。
9. ¿Sabes tocar el piano?
はい、できます。
10. Sí, sí puedo.
