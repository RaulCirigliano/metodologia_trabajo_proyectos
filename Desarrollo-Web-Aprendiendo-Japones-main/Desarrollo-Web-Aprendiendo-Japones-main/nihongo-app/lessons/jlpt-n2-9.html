JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 9

Tema: ~っぽい / ~だらけ (Parece / Lleno de)

📚 Gramática Principal

  • ～っぽい (ppoi): Significa 'Parece...' o 'Da la sensación de...'. Se usa de forma casual. También significa 'tiende a...' con ciertos verbos (ej. 怒いかりっぽい = tiende a enojarse), o para describir colores (ej. 白しろっぽい = blanquecino).
  • ～だらけ (darake): Significa 'Lleno de...' o 'Cubierto de...'. Se utiliza CASI SIEMPRE para cosas desagradables o negativas (ej. lleno de basura, cubierto de barro, lleno de errores).

この牛乳ぎゅうにゅうは少すこし水みずっぽくて、美味おいしくない。
2. Esta leche se siente un poco acuosa (aguada) y no sabe bien.
私わたしの弟おとうとは怒いかりっぽいので、すぐにケンカになる。
3. Mi hermano menor es propenso a enojarse (irascible), así que de inmediato se pelea.
母ははは最近さいきん、忘わすれっぽくなった。
4. Mi madre últimamente se ha vuelto olvidadiza.
あの白しろっぽい車くるまは、田中たなかさんの車くるまですか？
5. ¿Ese auto blanquecino es el auto de Tanaka?
大雨おおあめの中なかでサッカーをして、服ふくが泥どろだらけになった。
6. Jugué fútbol en medio de la lluvia fuerte y mi ropa se llenó de barro.
この文章ぶんしょうは間違まちがいだらけで、読よめない。
7. Este texto está lleno de errores y no se puede leer.
彼かの部屋へやはゴミだらけで、とても臭くさい。
8. La habitación de él está llena de basura y apesta mucho.
転ころんで、足あしが血ちだらけになってしまった。
9. Me caí y mis piernas se llenaron de sangre.
あのレストランのテーブルはホコリだらけだ。
10. Las mesas de ese restaurante están llenas de polvo.
