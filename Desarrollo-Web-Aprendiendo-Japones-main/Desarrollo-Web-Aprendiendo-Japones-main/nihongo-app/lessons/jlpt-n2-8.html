JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 8

Tema: ~を通つうじて / ~を通とうして (A través de / Durante todo...)

📚 Gramática Principal

  • ～を通つうじて (o tsuujite) / ～を通とうして (o tooshite): Ambos significan lo mismo y tienen 2 usos principales:
    1) 'A través de...' (como medio o intermediario). Ej: Conocerse a través de un amigo.
    2) 'Durante todo...' (un periodo de tiempo continuo). Ej: Hace calor durante todo el año.
