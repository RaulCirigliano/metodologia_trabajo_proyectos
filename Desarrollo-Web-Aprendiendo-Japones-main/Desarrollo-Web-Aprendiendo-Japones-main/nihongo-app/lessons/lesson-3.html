📚 Gramática Principal

  • ここ / そこ / あそこ / どこ: Aquí, Ahí, Allí, ¿Dónde?. Se refieren a lugares.
  • こちら / そちら / あちら / どちら: Por aquí, Por ahí, Por allí, ¿Por dónde?. Forma muy educada (Keigo) de indicar lugares, direcciones, o incluso personas.
  • N1 (Lugar/Cosa/Persona) は N2 (Lugar) です: Para indicar dónde está algo o alguien.
  • País / Empresa + の + Producto: 'Computadora de Apple', 'Vino de Francia'.
