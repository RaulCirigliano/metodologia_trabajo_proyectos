1. Nominalizar con の (Verbo como sujeto/objeto)

Podemos convertir una frase verbal en un sustantivo añadiendo の después del verbo en Forma Diccionario. Esto permite usarlo como sujeto (のは) o objeto (のが / のを).

絵えを描えがくのは楽たのしいです。
Dibujar cuadros es divertido. (~のは)
私わたしは星ほしを見みるのが好すきです。
Me gusta mirar las estrellas. (~のが好すき)

2. Olvidar o Saber (~のを)

Se utiliza para expresar que se ha olvidado hacer algo (忘わすれた) o que se sabe/conoce un hecho (知しっていますか).

薬くすりを飲のむのを忘わすれました。
Me olvidé de tomar la medicina.
