1. Forma Condicional (条件じょうけん形かたち - ~ば)

Se utiliza para expresar que una condición es necesaria para que ocurra un resultado ("Si A, entonces B"). Es muy común en proverbios, hechos de la naturaleza y manuales.

  • G1: Cambiar el sonido -i a -e + ば (ej. 書かく → 書かけば)
  • G2: Eliminar る y añadir れば (ej. 食たべる → 食たべれば)
  • G3: する → すれば / 来くる → 来これば (くれば)
  • Adjetivos -i: Eliminar い y añadir ければ (ej. 安やすい → 安やすければ)
春はるになれば、花はなが咲さきます。
Si llega la primavera, las flores florecerán. (Hecho natural)
安やすければ、買かいます。
Si es barato, lo compraré.

2. Condicional con ~なら

Se usa para Sustantivos y Adjetivos -na. Indica "en el caso de que sea...". También se usa para tomar un tema que acaba de mencionar otra persona.

温泉おんせんなら、箱根はこねがいいですよ。
Si hablamos de aguas termales, Hakone está muy bien.
