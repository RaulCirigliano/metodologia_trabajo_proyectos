1. Hacer en exceso (~すぎます)

Se añade a la raíz ます de un verbo, o eliminando la い/な de un adjetivo. Expresa que algo es excesivo o se ha sobrepasado un límite aceptable.

ゆうべお酒さけを飲のみすぎました。
Anoche bebí demasiado alcohol.
このセーターは大おおきすぎます。
Este jersey es demasiado grande.

2. Fácil o Difícil de hacer (~やすい / ~にくい)

~やすいです: Es fácil hacer la acción o tiene tendencia a ser así.

~にくいです: Es difícil hacer la acción.

Ambas formas se unen a la raíz ます de los verbos y funcionan como adjetivos tipo -i.

このパソコンは使つかいやすいです。
Esta computadora es fácil de usar.
東京とうきょうは住すみにくいです。
Tokio es difícil para vivir.
