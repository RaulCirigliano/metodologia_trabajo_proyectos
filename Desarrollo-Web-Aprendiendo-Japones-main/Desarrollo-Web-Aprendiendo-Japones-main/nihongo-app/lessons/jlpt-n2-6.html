JLPT N2 - 準備じゅんび

Examen para el JLPT2 - Lección 6

Tema: ~がち (Tendencia) / ~気味きみ (Ligeramente)

📚 Gramática Principal

  • ～がち (gachi): Significa 'Tender a...' o 'Ser propenso a...'. Se usa casi siempre para tendencias negativas o indeseables que ocurren a menudo (ej. 'tiende a enfermarse', 'tiende a llegar tarde').
  • ～気味きみ (gimi): Significa 'Tener un ligero toque de...' o 'Sentirse un poco...'. Se usa para expresar un estado físico o mental ligero (ej. 'un poco resfriado', 'un poco cansado').
