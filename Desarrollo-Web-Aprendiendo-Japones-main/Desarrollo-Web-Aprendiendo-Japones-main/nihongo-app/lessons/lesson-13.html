📚 Gramática Principal

  • N が 欲ほしいです: 'Quiero (objeto)'. Se usa para cosas tangibles o personas. La partícula que marca el objeto deseado es が.
  • V(masu) たいです: 'Quiero hacer (verbo)'. Se conjuga quitando el 'masu' y agregando 'tai'. Puede usar las partículas を o が.
  • N(Lugar) へ V(masu) / N に 行いきます: 'Ir a (Lugar) PARA (propósito)'. El propósito se marca con に.

🌟 10 Ejemplos de Uso

A continuación, 10 ejemplos prácticos utilizando la gramática aprendida en esta lección.

私わたしはパソコンが欲ほしいです。
1. Yo quiero una computadora.
今いま何なにが一番いちばん欲ほしいですか。
2. ¿Qué es lo que más quieres ahora?
新あたらしい車くるまが欲ほしいです。
3. Quiero un auto nuevo.
私わたしは沖縄おきなわへ行いきたいです。
4. Yo quiero ir a Okinawa.
お腹はらが痛いたいですから、何なにも食たべたくないです。
5. Como me duele el estómago, no quiero comer nada.
日本にっぽんへ美術びじゅつの勉強べんきょうに来きました。
6. Vine a Japón a estudiar bellas artes.
明日あした京都きょうとへお祭まつりをみに行いきます。
7. Mañana iré a Kioto a ver un festival.
冬休ふゆやすみはどこかへ行いきましたか。
8. ¿Fuiste a algún lado en las vacaciones de invierno?
はい、北海道ほっかいどうへスキーに行いきました。
9. Sí, fui a Hokkaido a esquiar.
喉のどが渇かわきましたから、何なにか飲のみたいです。
10. Como tengo sed, quiero beber algo.
