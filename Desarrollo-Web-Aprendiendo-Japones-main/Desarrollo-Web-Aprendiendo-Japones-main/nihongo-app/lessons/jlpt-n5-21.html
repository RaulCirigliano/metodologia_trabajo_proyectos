📚 Gramática Principal

  • Futsukei + と 思おもいます: 'Creo que...'. Expresa una opinión. La oración antes de 'to' debe ser informal.
  • Futsukei + と 言いいました: 'Dijo que...'. Para citar lo que alguien dijo.
  • ~でしょう？: '¿Verdad?'. Para buscar la confirmación del oyente.

🎧 Escucha el diálogo (Voces IA):

Ver Transcripción y Traducción
田中たなかさんは、明日あしたの天気てんきはどうなると思おもいますか？
Señor Tanaka, ¿cómo crees que estará el clima de mañana? (Pensamiento 'to omoimasu')
ニュースで、明日あしたは一日中いちにちじゅう雨あめが降ふると言いっていました。
En las noticias dijeron que mañana lloverá todo el día. (Cita 'to itte imashita')
えっ、本当ほんとうですか。私わたしは晴はれると思おもっていました。
¿Eh, de verdad? Yo pensaba que se iba a despejar. (Pensamiento en pasado)
残念ざんねんですね。明日あしたのピクニックはどうしますか？
Qué lástima. ¿Qué haremos con el picnic de mañana?
山田やまださんに電話でんわして、「ピクニックは来週らいしゅうにしましょう」と言いいます。
Llamaré al señor Yamada y le diré: 'Dejemos el picnic para la próxima semana'. (Cita directa)
それがいいと思おもいます。雨あめの中なかでピクニックは無理むりですから。
Creo que eso es lo mejor. Porque un picnic en la lluvia es imposible. (Pensamiento)
そうですね。山田やまださんも賛成さんせいすると思おもいます。
Es cierto. Creo que el señor Yamada también estará de acuerdo.
