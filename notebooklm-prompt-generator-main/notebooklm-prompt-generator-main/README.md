# Generador de Prompts para NotebookLM

Una aplicación web ligera diseñada para crear "prompts" (instrucciones) personalizados para usar en **Google NotebookLM**. La herramienta genera un "Prompt Maestro" general y varios prompts específicos basados en la categorización de los documentos de tu proyecto (como los capítulos de un libro, entrevistas, etc.).

## Características

- 🎨 **Diseño Premium**: Interfaz moderna "Dark Mode" con efectos de *glassmorphism*.
- ⚙️ **Sin dependencias**: Escrito enteramente en HTML, CSS y JavaScript puro. Funciona sin necesidad de instalar NodeJS o un servidor de desarrollo.
- 📋 **Copiar con un clic**: Botones integrados para copiar rápidamente los prompts generados y pegarlos en NotebookLM.
- 🧠 **Contextual**: Adapta los prompts al objetivo principal de tu análisis (Resumen, Guía de Estudio, Análisis Profundo, etc.) y al tono deseado.

## ¿Cómo usar?

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Safari, Firefox).
3. Completa los datos en el panel izquierdo:
   - Nombre de tu proyecto.
   - El objetivo principal que buscas en NotebookLM.
   - Escribe una categoría de documento por línea (ej: "Capítulos", "Fichas de Personajes").
   - Selecciona el tono de respuesta.
4. Haz clic en **"Generar Prompts"**.
5. Copia los prompts resultantes de la columna derecha y úsalos como instrucciones iniciales en tu proyecto de NotebookLM.
