# 🎬 VisualFlow - Premium Image-to-Video Compiler

VisualFlow es una aplicación web de alto rendimiento diseñada para crear presentaciones de video profesionales directamente en el navegador. Combina la potencia de **HTML5 Canvas** con la **MediaRecorder API** para ofrecer una experiencia de edición fluida, sin necesidad de servidores ni procesamiento externo.

![VisualFlow Preview](https://via.placeholder.com/1200x600?text=VisualFlow+Interface+Preview)

## ✨ Características Principales

- **🖼️ Compilación de Imágenes**: Importa fotos mediante arrastrar y soltar (Drag & Drop) o selector de archivos.
- **🔡 Diapositivas de Texto**: Intercala diapositivas con texto personalizado y fondos sólidos para narrar tu historia.
- **🎞️ Transiciones Cinematográficas**: 
  - **Fade**: Transición suave de transparencia.
  - **Slide**: Movimiento lateral dinámico.
  - **Zoom**: Efecto de escala profesional.
- **⏱️ Control de Tiempos Preciso**: Ajusta la duración global o individual de cada diapositiva directamente en la línea de tiempo.
- **🔃 Reordenamiento Intuitivo**: Cambia el orden de tus fotos simplemente arrastrándolas por la línea de tiempo.
- **🎵 Integración de Audio**: Añade una pista de música de fondo sincronizada con tu presentación.
- **📥 Exportación Directa**: Genera videos en formato `.webm` (VP9/5Mbps) listos para compartir.

## 🛠️ Stack Tecnológico

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Properties).
- **Gráficos**: HTML5 Canvas API para renderizado en tiempo real.
- **Video**: MediaRecorder API para captura y codificación de video en el cliente.
- **Iconografía**: [Lucide Icons](https://lucide.dev/).
- **Tipografía**: Google Fonts (Inter).

## 🚀 Instalación y Uso

No requiere instalación de dependencias ni servidores.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/visualflow.git
   ```
2. Abre `index.html` en cualquier navegador moderno (Chrome o Edge recomendados para mejor rendimiento en la exportación).

### Pasos para crear un video:
1. Sube tus fotos a la zona de **Archivos**.
2. Añade **Diapositivas de Texto** si lo necesitas.
3. Organiza el orden arrastrando las miniaturas.
4. Ajusta los **segundos** y **transiciones** de cada diapositiva.
5. (Opcional) Sube un archivo de **audio**.
6. Haz clic en **Exportar Video**.
